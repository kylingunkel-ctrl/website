Free and Pro

One app, two ways to use LocalStream

LocalStream is one Windows installer with a Free edition for smaller libraries and a Pro upgrade path planned for larger collections and additional tools.

LocalStream Free

Free

Designed to let you start with the core LocalStream experience and explore your personal video library without an account.

  • Core local playback
  • Search, sort, and filters
  • Thumbnails and previews
  • Watch progress
  • Favourites
  • Tags and playlists
  • Themes

LocalStream Pro

NZD$42.99 planned one-time

Intended for larger libraries, more locations, and the extra tools that make moving and maintaining a personal video collection easier.

  • Unlimited videos
  • Multiple library locations
  • Backup and restore
  • Move library setup between computers
  • Advanced thumbnail and cache tools
  • Library health and reconnect tools
  • Supported 3D viewing

One installer

One installer. Start Free. Upgrade anytime.

Install LocalStream once and start with the Free edition. When Pro checkout is ready, the same app will be able to unlock Pro with a valid licence if you want the additional features.

There is not a separate Pro installer. The website will show the purchase steps once that flow is publicly available.

System requirements

What is known today

  • Windows desktop application
  • Additional local storage may be used for thumbnails and cache
  • Limited internet access is only needed for release-related functions such as downloads, support links, and licensing when available

For best results, use common video formats supported by Windows and keep enough free disk space for thumbnails and cache.

Installation process

How to install

  1. Download LocalStream Free from the official website.
  2. Run the Windows installer.
  3. Open LocalStream.
  4. Choose your video folder.
  5. Start browsing your library.
  6. Upgrade to Pro later if you want the additional features.
