Free and Pro

One app, two ways to use LocalStream

LocalStream is being prepared as one Windows installer with a Free edition for smaller libraries and a Pro upgrade path for larger collections and additional tools.

LocalStream Free

Free

Designed to let you start with the core LocalStream experience and explore your personal video library without an account.

  • Core local playback
  • Search, sort, and filters
  • Thumbnails and previews
  • Watch progress
  • Favourites
  • Tags and playlists
  • Themes

LocalStream Pro

US$24.99 planned one-time

Intended for larger libraries, more locations, and the extra tools that make moving and maintaining a personal video collection easier.

  • Unlimited videos
  • Multiple library locations
  • Backup and restore
  • Move library setup between computers
  • Advanced thumbnail and cache tools
  • Library health and reconnect tools
  • Supported 3D viewing

Final Pro purchase flow will appear here when public release and checkout are ready.

One installer

One installer. Start Free. Upgrade anytime.

This is how the final release is intended to work: install LocalStream once, start with the Free edition, and unlock Pro later with a valid licence if you want the additional features.

There will not be a separate Pro installer. The website will show the actual licensing steps once that flow is publicly available.

System requirements

What is known today

  • Windows desktop application
  • Additional local storage may be used for thumbnails and cache
  • Limited internet access may only be needed for release-related functions such as licensing, when available

Final system requirements will be published before release.

Installation process

When released

  1. Download LocalStream from the official website.
  2. Run the Windows installer.
  3. Open LocalStream.
  4. Choose your video folder.
  5. Start browsing your library.
  6. Upgrade to Pro later if you want the additional features.

Download LocalStream safely
