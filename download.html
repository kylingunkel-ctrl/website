Installation process

How to install

  1. Download FolderStream Free from the official website.
  2. Run the Windows installer.
  3. Open FolderStream.
  4. Choose your video folder.
  5. Start browsing your library.
  6. Upgrade to Pro later if you want the additional features.

Safe download guidance

Download FolderStream safely

Only download FolderStream from the official FolderStream website or another download source explicitly linked from it.

Official source: folderstream.co.nz

FolderStream is a new, unsigned app, so your browser or Windows may say it is not commonly downloaded or that the publisher is unknown. These warnings are expected and nothing to worry about when you use the official FolderStream download button.

Using Microsoft Edge? Choose Keep → Keep anyway. Other browsers may use different wording. When Windows checks the installer, choose More info → Run anyway.
